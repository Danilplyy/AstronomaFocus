# АРСЕНАЛ — технологическое древо

## Установка и запуск
1. Установите зависимости: `npm install`.
2. Настройте `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (только для `npm run seed`, не используйте в браузерном коде).
3. Выполните `supabase/schema.sql` в Supabase SQL Editor. Для уже работающего проекта достаточно выполнить `supabase/migration_dynamic_countries.sql`.
4. Запустите `npm run seed`, чтобы загрузить 600 уникальных фокусов на каждую страну из списка seed и создать записи стран.
5. Запуск сайта: `npm run dev`; production-сборка: `npm run build`.

## Что изменено
- Для каждой из 6 веток подготовлено по 100 самостоятельных фокусов: 10 этапов по 10 уникальных тем.
- У каждого фокуса отдельное название и описание; больше нет повторения базового названия с одинаковыми приставками.
- Каталог фокусов вынесен в `src/focus-catalog.mjs` и используется как демонстрационным режимом, так и seed-скриптом.
- Страны хранятся в таблице `public.countries`, а не в жёстко заданном массиве фронтенда.
- Администратор может добавлять страны по названию и коду, а также удалять свободные страны.
- Удаление страны блокируется, если за ней закреплён игрок. Сначала переназначьте игрока; удаление страны также удаляет её фокусы и связанные заявки.
- Регистрация показывает только свободные страны.
- Копирование немецкого дерева поддерживает любые добавленные страны (кроме самой Германии).

## Важно
`npm run seed` обновляет фокусы с теми же идентификаторами. Названия и описания существующих фокусов будут заменены новым каталогом, а идентификаторы сохраняются, чтобы не ломать ссылки заявок игроков. Перед запуском на действующей кампании сделайте резервную копию базы.
